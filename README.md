# Blue Ridge Mountain Civic Association

Website for the Blue Ridge Mountain Civic Association (BRMCA), a 501(c)(4) civic organization serving residents along Route 601 in Clarke and Loudoun Counties, Virginia.

**Live site:** [nobler1050.github.io/BRMCA](https://nobler1050.github.io/BRMCA)

## About

BRMCA was founded in 2003 to safeguard the natural environment of the Blue Ridge and foster community among mountain residents. This site is a static HTML/CSS/JS site hosted on GitHub Pages, migrated from Wix to reduce costs.
